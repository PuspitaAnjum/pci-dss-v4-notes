# PCI DSS Requirement 1

## Network Security Controls

### Objective

Protect cardholder data by implementing and maintaining network security controls.

### Key Controls

- Firewalls
- Network Segmentation
- Inbound Traffic Restrictions
- Outbound Traffic Restrictions
- Router Security

### Why It Matters

Attackers often target network weaknesses to gain access to sensitive systems.

### Evidence Examples

- Firewall Rule Reviews
- Network Diagrams
- Configuration Standards
- Change Management Records

### Interview Question

What is the purpose of network segmentation in PCI DSS?

### Answer

Network segmentation helps reduce PCI DSS scope and limits attacker movement between systems.
